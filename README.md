​1. ¿Por qué ArrayList o LinkedList NO son aceptables?
​Las listas ArrayList y LinkedList son dificiles para hacer operaciones de busqueda o validaciones. El sistema tiene que buscar el secuencialmente el username y con las listas ArrayList y LinkedList no es facil.

​2. ¿Por qué HashSet NO resuelve el problema por sí solo?
​Un HashSet guarda un conjunto de elementos únicos sin una clave a un valor ordenado.

​3. ¿Por qué TreeMap NO es la opción ideal?
​TreeMap almacena las claves internamente.

​4. Estructura Seleccionada: HashMap
​La única estructura que nos ayudo para resuelve todas las operaciones requeridas en tiempo.
